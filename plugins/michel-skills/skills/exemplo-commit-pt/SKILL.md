# Mensagens de commit em português

Skill de exemplo. Substitua pelo seu próprio conteúdo ou use como modelo.

## Instruções

1. Rode `git diff --staged` para ver o que será commitado.
2. Escolha o tipo: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`.
3. Escreva no formato `tipo(escopo): descrição curta no imperativo`.
4. Se a mudança não for óbvia, adicione um corpo explicando o **porquê**.

## Exemplo

```
feat(checkout): adiciona validação de CEP

O formulário aceitava CEPs inválidos, gerando erro no cálculo de frete.
```
